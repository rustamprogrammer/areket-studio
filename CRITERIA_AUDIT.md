# Проверка по Final Project Criteria

Источник: приложенный `Final Project Criteria.pdf` (4 страницы). Проверка кода выполнена 18 ноября 2026 года. Баллы ниже не выставляются автоматически: часть критериев проверяется только на живой демонстрации и устной защите.

| Критерий | Вес | Что есть в проекте | Статус |
| --- | ---: | --- | --- |
| Структура и страницы | 5% | Три связанные HTML-страницы, общая навигация и подвал | Реализовано |
| Единый дизайн и удобство | 5% | Общие цвета, шрифты, компоненты и оформление проектов | Реализовано; визуальная проверка в браузере нужна |
| Адаптивность и доступность | 10% | Точки перелома, alt, ARIA, подписи формы, видимый фокус, reduced motion. Исправлена ширина колонок формы; ошибки связаны с полями. Проверен контраст ключевых цветов, включая тёмную тему | Код проверен; нужен просмотр на устройствах |
| Bootstrap и собственный CSS | 15% | Bootstrap container/row/cols и отдельная система стилей | Реализовано |
| JavaScript и jQuery | 20% | Загрузка JSON, поиск и фильтры, диалог проекта, валидация формы, история запросов в localStorage, язык, тема, подготовка сообщения WhatsApp, реакция фона на курсор | Реализовано; нужна живая демонстрация |
| Качество кода и оптимизация | 5% | Общие CSS/JS, отдельный JSON, локальные SVG, отложенная загрузка изображения ниже первого экрана. JavaScript и статические проверки проходят | Реализовано; внешний CDN требует интернет |
| Командная защита | 30% | Сценарий демонстрации и вопросы в `DEFENSE.md` | Оценивается преподавателем во время выступления |

## Бонусы

- JSON: данные проектов загружаются через `fetch()` из `data/projects.json` — до +5%.
- Локализация: RU/EN применяется ко всем трём страницам и сохраняется в `localStorage` — до +5%.
- Есть также собственный диалог, тёмная тема и поиск/фильтры. Общий бонус по PDF ограничен +10%.

## Условия проверки

На HTTP проект загружает JSON через `fetch()`. При открытии `projects.html` как файла используется совпадающая копия данных в `data/projects.js`; `verify.py` проверяет их равенство. Bootstrap, jQuery и шрифты загружаются из CDN. Проверки `python verify.py`, `node --check assets/js/app.js` и `git diff --check` прошли. Полный визуальный прогон в браузере в этой среде не завершён; перед защитой следует проверить ширины 390, 768, 1024 и 1440 px, тёмную тему, клавиатуру и сценарий из `DEFENSE.md`.
